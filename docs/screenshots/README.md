# Thư mục ảnh chụp màn hình phục vụ báo cáo.

Quy ước đặt tên (WORKFLOW.md mục 12.3):

```
docs/screenshots/<module>/<mô-tả>-<YYYYMMDD>-<số>.png
```

Ví dụ:

```
docs/screenshots/order/order-merge-table-20261120-01.png
docs/screenshots/reports/revenue-dashboard-20261127-01.png
docs/screenshots/db/erd-20261115.png
```

Yêu cầu:

- Chụp **cả cửa sổ**, dữ liệu thật (không để trống), chiều ngang ≥ 1280px
- Không để lộ thông báo cá nhân (Zalo, email, trình duyệt)
- Mỗi ảnh dùng trong báo cáo phải có caption
- Lưu ảnh **ngay khi làm xong tính năng**, đừng dồn tuần cuối
